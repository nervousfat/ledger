# JSON 备份协议

完整备份包含应用标识、协议版本、预算和账目数组。最小示例：

```json
{
  "app": "pocket-ledger",
  "version": 1,
  "budgetCents": 0,
  "entries": []
}
```

每条记录使用 [账目结构](entry-schema.md) 中的六个字段。备份中每条记录必须明确提供 id，且规范化后不能重复。最多 10,000 条记录，预算是非负整数分。未知版本会拒绝，不会猜测或部分导入。

备份上限为 5,000,000 个 UTF-8 字节，等于十进制 5 MB，包含 JSON 标点、缩进和空白。汉字通常占三个 UTF-8 字节，因此不能用 JavaScript 字符数判断文件大小。导出和导入采用相同限制；成功导出的文本可以再次通过核心导入校验。

超限导出会明确报错，不截断记录，也不更改原集合。界面的 JSON 备份下载包含全部账目和预算，不受当前筛选条件影响，也不支持自动分卷或按筛选结果分批导出 JSON。

开发者可以直接调用 `core.exportBackup(entriesSubset, budgetCents)` 序列化一个明确选择的记录子集；这是领域 API 的能力，并非现成的界面操作。部分备份不会自动合并，且界面导入会替换全部现有账目和预算，不能通过依次导入多个部分文件恢复完整账本。

导入先完整验证再返回新集合。调用方应在验证成功后一次性替换现有状态；出现错误时保留现有记录和原文件。

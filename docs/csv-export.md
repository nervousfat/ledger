# CSV 交换格式

导出使用 UTF-8，并带 BOM，方便常见电子表格软件识别中文。第一行固定为日期、类型、分类、金额（元）、备注五列。行分隔符是 CRLF；字段内部的换行仍保留。

每个字段均包在双引号中，字段中的双引号写两次。分类或备注含逗号时仍属于同一列。因此不能用简单的逗号分割或逐行分割来读取任意合法导出文件，应使用支持标准引号规则的 CSV 读取器。

金额使用元及固定两位小数，收入/支出保存在独立类型列。文本中可能被电子表格解释为公式的前缀会添加文本标记；该标记属于展示兼容措施，不适合当作原始文本备份。

CSV 不包含账目 id 或预算，也不是本项目 JSON 导入的输入格式。需要恢复完整账本时保存 JSON；需要交给电子表格汇总时使用 CSV。空集合仍生成列标题。

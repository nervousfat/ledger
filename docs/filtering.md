# 筛选语义

`filterEntries(entries, { month, type, query })` 返回经过规范化的新数组。所有启用的条件同时满足才保留记录；空字符串表示该条件未启用。

月份使用 YYYY-MM，收支类型仅接受 income 或 expense。关键词去除首尾空白并忽略大小写，查找分类与备注拼接的文本。查询是连续子字符串，不是正则表达式，也不会把多个词拆开分别匹配。

例如月份 2025-12、类型 expense、关键词 Train 会选出当月备注或分类包含该文字的支出。没有结果返回空数组；无效月份和类型会抛错，不能把输入错误误认为正常空结果。

返回结果按日期倒序，同一天按 id 排序。调用筛选不会修改源集合。连续执行月份、类型、关键词筛选应等价于一次传入三个条件；相关性质由 `tests/filter-algebra.test.js` 验证。

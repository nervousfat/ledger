# 汇总与分组

总汇总包含 income、expense、balance、count。前三项使用整数分，balance 等于收入减支出；空集合各项为零。传入筛选结果即可得到该范围的汇总，传入全部记录则得到全账本汇总。

分类汇总默认只包含支出，也可以传 income 汇总收入。每项包含 category、cents、share；share 是该分类占所选收支类型总额的比例，范围为 0–1，不是百分数。展示为百分比时再乘 100。四舍五入后的展示百分比可能不能正好相加为 100%。

分类按金额倒序，同金额按分类名排序。月度分组按 YYYY-MM 倒序，跨年时 2026-01 位于 2025-12 前面。无记录的月份不会凭空创建零值分组。

月度的各项汇总相加应等于全账本汇总；收入分类金额之和应等于总收入，支出同理。`tests/summary-partitions.test.js` 用一组跨年、多分类记录验证这些一致性关系。

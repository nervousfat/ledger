# 验证与预算规则

在仓库目录执行 `npm test`，Node 会发现原有 `core.test.js` 和 `tests/*.test.js`。测试无需浏览器、网络或第三方依赖；数据在内存生成，不写入浏览器账本。执行 `npm run check` 检查脚本语法。

专题测试按领域行为组织：金额往返、公历边界、规范化、稳定排序、容量、错误原子性、筛选交集、分组对账、CSV 结构、UTF-8 备份、恢复和预算阈值。单独执行某个文件适合定位失败；修改公共逻辑后运行完整测试，避免只验证成功路径。

预算是一个适用于每月的金额，不是按月份保存的独立表。`budgetStatus` 只汇总指定月份的全部支出，收入不抵减支出；若预算为零，则 configured 为 false、ratio 为零。恰好用完预算时 remaining 为零但 exceeded 为 false，只有超出才标记超额。

示例账目每次生成六条独立 id 的记录，调用者应指定 YYYY-MM。示例仅供体验，可编辑和删除；反复加入会形成多批真实独立记录，统计也会一并计入。

浏览器持久化、下载交互和多窗口事件不属于这些领域单元测试。检查界面时应另外确认：导出后能重新导入、存储失败有明确提示、损坏原始数据能够保留、取消操作不改变状态。

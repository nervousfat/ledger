# 金额模型

金额在领域层使用整数分，100 分等于 1 元。分类统计、余额、预算都使用同一种单位，不把元的小数直接相加。

`parseMoney('0.29')` 返回 29；`parseMoney('12.3')` 返回 1230。字符串首尾空白会被移除，整数和一位小数允许输入，但千位逗号、前导零、科学计数法、负数和超过两位的小数会拒绝。数字参数也必须能够转换为这种明确的十进制格式。

解析允许零，用于未设置的预算；账目金额必须大于零。单笔金额及预算上限为 100,000,000,000 分，即 1,000,000,000.00 元。

格式化只接受安全整数分，可显示负余额。例如 `formatMoney(-1)` 为 `-¥0.01`。展示中的货币符号和千位逗号不是可再次解析的输入；备份应保存整数分，不保存展示字符串。

运行 `node --test tests/money-properties.test.js` 验证临界金额、数字输入和往返性质。

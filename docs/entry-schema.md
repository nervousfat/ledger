# 账目结构

每条账目由六个字段组成，规范化返回新对象，不保留未知字段。

| 字段 | 类型与限制 |
| --- | --- |
| id | 1–80 个 ASCII 字母、数字、下划线或连字符；省略时生成 |
| type | income 或 expense |
| cents | 大于零的安全整数分，不超过 100,000,000,000 |
| category | 去除首尾空白后非空，最多 40 个 UTF-16 单元 |
| note | 可省略，默认为空字符串，最多 300 个 UTF-16 单元 |
| date | 1900–2100 年间的有效 YYYY-MM-DD 日期 |

分类不局限于预设列表。文本长度目前使用 JavaScript 字符串长度，部分 emoji 占两个单元；调用端应采用同样的边界，避免先显示可用又在保存时失败。

`normalizeEntry` 校验一条记录，不保证集合内 id 唯一。身份重复和集合容量由集合操作或备份校验负责。更新账目时应传原 id 作为独立参数，不用编辑内容来替换身份。

不要将规范化视为数据恢复工具：无法识别的金额、缺少必填分类或错误日期都会明确抛错，调用方应保留原输入以便更正。
